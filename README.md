Generador de Paletas de Colores
Descripción
Generador de Paletas de Colores es una aplicación web estática desarrollada como proyecto integrador del Módulo 1 de Full Stack.

Esta primera fase presenta una muestra estática de un color y sus valores de referencia. La estructura inicial permite incorporar nuevas funcionalidades en etapas posteriores.
Estado del proyecto
Fase 1: muestra estática de color.

La aplicación presenta el color azul índigo #414DE8, junto con su nombre y sus valores en los formatos HEX y HSL.

En esta versión no se generan colores aleatorios ni se utilizan controles interactivos. La interfaz está construida con HTML y CSS.
Tecnologías utilizadas
- HTML5: estructura y contenido de la aplicación.
- CSS3: presentación visual, distribución de elementos y adaptación a diferentes tamaños de pantalla.
- Git: control de versiones.
- GitHub: alojamiento del repositorio y publicación del sitio mediante GitHub Pages.

Ejecución local
La aplicación no requiere instalación de dependencias ni servidor backend.

Para visualizarla localmente:
1. Descargar o clonar el repositorio.
2. Abrir el archivo index.html en un navegador web.
También puede utilizarse la extensión Live Server de Visual Studio Code para iniciar una vista local durante el desarrollo.
Publicación
El proyecto está preparado para publicarse mediante GitHub Pages. La configuración de publicación utiliza la carpeta raíz del repositorio como origen del sitio.

Una vez habilitado GitHub Pages y completado el flujo de publicación, la aplicación estará disponible en la dirección asignada por GitHub.
Funcionalidades incluidas
- Presentación de una muestra de color estática.
- Visualización del código HEX.
- Visualización del nombre del color.
- Visualización del valor HSL.
- Diseño adaptable a distintos tamaños de pantalla.
Próximas etapas
Las siguientes funcionalidades podrán incorporarse progresivamente:
- Generación de colores aleatorios.
- Visualización de varios colores en una misma paleta.
- Copiado de códigos de color.
- Bloqueo de colores seleccionados.
- Opciones adicionales de formato y gestión de paletas.
